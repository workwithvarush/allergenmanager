07 Usage rules
Do
✓ Use Forest as the primary action colour throughout
✓ Reserve Gold exclusively for the Print action
✓ Use ✕ marks in red for allergen present — consistent with existing sheets
✓ Show version stamp on every generated document
✓ Use warning amber for last-minute change banners
✓ Keep one primary button per screen — never two
✓ Use DM Mono for all version stamps and code tokens
Don't
✗ Use red for anything other than allergen present or error states
✗ Use Gold outside of the print action context
✗ Place more than one primary button on a screen
✗ Use icon-only buttons for primary or destructive actions
✗ Hardcode spacing — always use token variables
✗ Mix V, VG, NCGI tag colours across contexts
✗ Allow "contains" field to be manually edited — it must be auto-only
